# PaperLoom

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](./LICENSE)
[![Latest Release](https://img.shields.io/github/v/release/GreyWolf1101/PaperLoom-Releases)](https://github.com/GreyWolf1101/PaperLoom-Releases/releases/latest)

PaperLoom 是一款本地优先的 Windows 桌面阅读与研究工作台，支持 PDF、DOCX、EPUB、TXT、Markdown、HTML 和 FB2，并提供精确目录跳转、标注、翻译、AI 总结、研究项目管理、书籍阅读与 AI 小说创作。

## 开发中：公式工坊

- 实用工具新增“公式工坊”，支持上传、拖入或粘贴印刷公式和手写公式截图，并调用用户自行配置的多模态 AI 模型识别为可编辑 LaTeX。
- 支持使用自然语言描述生成公式，也可以通过可视化公式键盘编写上下标、分式、根式、求和、积分、分段函数以及 2×2 / 3×3 矩阵等复杂公式。
- 新增所见即所得数学画布，可直接点击公式中的数字、符号和待填写空位进行编辑；画布与 LaTeX 源码实时双向同步，未完成的空位会明确提示并阻止误导出。
- 使用 KaTeX 在本地实时排版并检查公式语法；当前草稿和公式编号自动保存在本机。
- 支持复制 LaTeX、MathML，并通过 Word 官方 MathML 剪贴板格式直接粘贴为原生公式；也可导出包含原生 OMML 对象与右侧公式编号的 `.docx` 文件，复制与导出结果都可在 Microsoft Word 中继续编辑。
- 图片只在用户主动点击识别时发送至其配置的 AI 服务；公式编辑、排版和 Word 导出均在本地完成。

## 0.9.0 研究项目工作台

- 证据卡片：选中论文原文即可保存为观点、方法、结果、数据、局限、引文、疑问或灵感，并保留文献、页码与原文坐标。
- 多论文对比：围绕研究项目离线提取研究问题、方法、样本、指标、结论与局限；也可使用 AI 深化，但只有能映射到真实来源的字段才会采用。
- 引用导航：本地解析参考文献章节，支持 Crossref 元数据补全、Semantic Scholar 引用与被引关系，并可返回参考文献原页。
- 研究项目：将研究问题、项目文献、证据卡片和比较矩阵统一组织并自动保存在本地。
- 全库检索：在本机跨论文检索正文，所有结果附带论文、页码和可跳转原文位置。

## 0.8.8 AI 书稿双缩放

- AI 创作书稿工具栏新增独立的“文字缩放”和“页面缩放”，范围均为 80%–140%，每次调整 10%。
- 文字缩放只调整书名、章节、小节与正文，不改变纸张尺寸；页面缩放会整体改变书页和版心。
- 两组缩放不会影响普通文献或书籍阅读器，并会与 AI 创作布局一起自动保存在本机。
- 窄窗口下缩放组件和书稿操作按钮会自动压缩，避免工具栏拥挤或遮挡。

## 0.8.7 创作格式与左右布局

- AI 创作中的讨论和修改建议支持 Markdown 安全渲染，`**加粗内容**` 会显示为真正的粗体，不再暴露星号。
- 书稿排版不再把普通短句误判成小标题；只有明确的章节、场景和编号小节才使用加粗标题样式。
- AI 创作工具栏新增左侧/右侧布局选择，并自动保存用户选择；收起后的恢复栏也会跟随所选方向。
- 工具栏位于右侧时，左侧折叠书库标签不会再挤压创作输入框。

## 0.8.6 AI 命名与创作概述

- 新作品不再以大号“未命名作品”占据书页；首次创作前使用轻量提示，首次生成时由 AI 根据题材、人物和正文生成正式书名。
- AI 创作响应固定分为书名、剧情概述和正文；应用只把章节与正文写入右侧书稿，元数据不会混入正文。
- 左侧创作回执显示书名、本次任务、剧情概述和写入字数，便于快速回顾创作脉络，同时不重复展示小说全文。
- 对未按格式返回书名或剧情概述的模型增加轻量元数据补全，主正文不会因补全失败而丢失。
- 收起书库后，AI 创作输入区会为边缘恢复标签预留空间，不再遮挡输入文字。

## 0.8.5 创作会话与折叠布局

- 左右主工具栏收起后改为贴合窗口边缘的竖向标签，不再覆盖 AI 创作等页面标题；论文与书籍主题使用各自的协调配色。
- AI 创作栏可以单独收起，收起后右侧书稿自动扩展，并可从窄边栏恢复。
- 每部作品拥有独立且自动保存的书稿和对话；新建作品不会清空旧会话，可从作品会话列表随时切换。
- “创作”生成的长正文只写入右侧书稿，左侧仅保留简短的完成记录；讨论和重写结果仍保留在对话中。
- AI 返回的书名会用于作品标题，人物设定、故事冲突、提纲、分隔线和创作说明会从正文中剥离，书页只显示书名与小说正文。
- 现有 0.8.4 单作品草稿会在首次打开时自动迁移到新的多作品工作区。

## 0.8.4 小说排版、复制与 AI 创作

- 书籍模式会识别“第×章”“Chapter”“序章”“尾声”等真正章节，并使用更醒目的实体书式标题排版；普通小标题保持较低层级。
- 阅读区选中文字后可直接复制；跨段选择会进入安全的“仅复制”模式，不影响原有总结、翻译和重点标记。
- 文章小说阅读主题新增独立的 AI 创作工作区，复用应用内已有的 AI 模型配置。
- AI 创作支持续写、讨论与重写选段三种模式，可根据主题、人物、视角、文风和已有上下文持续生成。
- 生成内容以书稿页面排版显示，草稿和最近对话自动保存在本机；支持复制全文与导出 TXT。
- 在书稿中选择文字后，可向 AI 询问人物、情节、节奏、语言等问题，也可生成替代版本并一键替换原选段。
- 创作请求最多携带当前书稿的相关上下文，不会上传书库中的其他书籍或文献。

## 0.8.3 长文档性能优化

- PDF 文本索引改为分批并发解析，并在批次间释放界面线程。
- PDF 阅读区只挂载视口附近页面的画布和文本层，远处页面使用轻量占位。
- Word、EPUB、TXT、Markdown、HTML、FB2 等可重排文档按段落分块虚拟渲染。
- 搜索采用延迟计算，重点标记与批注按段落预先索引，避免滚动时反复扫描全部数据。
- 目录、笔记、翻译、标注和阅读位置支持跨虚拟分块精确跳转。

PaperLoom 是一款 Windows 桌面长文阅读器。应用左下角可在“论文阅读”和“文章小说阅读”之间切换：论文模式保持原有研究工作台，书籍模式提供独立书库、书架、阅读记录与书籍搜索；两种模式的数据不会混在一起，所选模式也会跨重启保留。

论文模式在本地解析 PDF 与 DOCX，提供原貌阅读、原始目录/三级标题目录、精确页码跳转、全文搜索、重点标记、段落翻译、AI 选段总结、全文总结、文献截图图库与 Markdown 笔记导出。图库支持在阅读区拖动框选图表、公式或重要内容，截图按文献隔离保存在本地；点击缩略图可准确返回截图位置，删除文献或截图时也会同步清理对应图片。段落翻译和选段总结均可显示在 PDF 原文下方或页面侧边；总结原文使用柔和的蓝灰色单一虚线轮廓定位，整段选择显示为大矩形，从行中间开始的跨行选择显示为贴合文字范围的多边形，并始终收束在用户选中的最后一行，与翻译波浪线清晰区分。

书籍模式支持 EPUB、TXT、Markdown、HTML、FB2、PDF 与 DOCX。EPUB 会读取书名、作者、出版社、章节顺序、原生导航目录与书内注释链接；正文中的脚注或尾注标记可直接跳转到对应注释。没有原生目录的文本书籍会按章节标题自动生成目录，并绑定到本地正文位置。应用会按书保存阅读位置与最后打开的书籍，重启后自动重新载入本地正文并恢复到上次看到的位置。Word、EPUB、TXT 等可重排格式在工具栏中分别提供文字缩放与整页缩放；PDF 保留单独的页面缩放。

学术发现界面可直接检索 OpenAlex、Crossref、Semantic Scholar 与 PubMed 的公开文献元数据，在软件内比较题名、作者、摘要、年份、期刊、引用量和开放获取状态。中国知网、万方、Google Scholar、arXiv、IEEE Xplore、ScienceDirect 与 Springer Nature 保留官网检索入口；点击阅读或下载时由对应官方页面处理权限。

书籍搜索可直接查询 Open Library、Google Books、Project Gutenberg 与 Internet Archive，在软件内比较封面、书名、作者、出版年份、版本、ISBN、内容简介、电子书格式和访问方式。豆瓣读书与微信读书保留带当前检索词的官方入口；预览、借阅、下载或购买仍由对应官网处理权限。

## 自动更新发布

应用设置新增“版本与更新”页面，支持启动时自动检查、手动检查、显示版本说明、下载进度，以及下载完成后重启安装。自动更新仅面向 Windows NSIS 安装版；便携版可以检查和下载更新，但完成更新时会迁移到安装版，本地文献记录、批注和设置会继续保留。

更新地址已经配置为 `https://github.com/GreyWolf1101/PaperLoom-Releases/releases/latest/download/`。后续每次递增 `package.json` 版本号后执行：

```bash
npm run dist:update
```

每个版本都创建独立的 GitHub Release。小版本更新会利用新旧 `.blockmap` 仅下载变化数据；大版本更新会自动改用完整安装包。发布脚本会在小版本发布目录中附带上一版本的 blockmap，请与新安装程序、新 blockmap 一起上传，并最后上传 `latest.yml`。完整操作与安全要求见 [自动更新发布指南](./自动更新发布指南.md)。

AI 功能支持 OpenAI 兼容接口，也可以连接本机 Ollama 或 LM Studio。接口地址、模型与 API Key 在应用设置中填写；API Key 使用 Electron `safeStorage` 加密保存在本机。

翻译可在设置中选择“AI 模型翻译”或“专用翻译”。专用翻译支持 MyMemory、百度翻译、网易有道翻译、DeepL API Free、Microsoft Translator 与 Google Cloud Translation；其中 MyMemory 可以不填写账号或密钥直接使用，其他服务需要各自的翻译 API 凭据。每个服务都在设置中提供官方说明入口。翻译密钥与 AI Key 分开保存，并使用 Electron `safeStorage` 加密。

PDF、Word、EPUB 与其他书籍原文件不会被上传，目录与正文也只在本地解析。只有用户主动执行总结或翻译时，相应文本才会发送到配置的 AI 接口或专用翻译服务；软件不会把整篇文献或书籍发送给翻译厂商。学术检索与书籍检索只向相应公开数据源发送检索词。
